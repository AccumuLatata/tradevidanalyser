# Coach ↔ ThesisTester rules

Approved 2026-10-31 (Accumu). These rules are the desk contract for
how the Trading Coach and the ThesisTester bot work together. They
do not change code.

1. The Trading Coach only proposes studies. A proposal names the
   thesis, the data, the period, and the reason, and states beforehand
   which result would support the thesis and which result would refute
   it.
2. No study starts without Accumu's OK.
3. Only the Thesistester bot runs studies, on the farm PC, with locked
   code.
4. Thesis Tester Results evaluates the runs. They are logged in
   Notion.
5. The Coach never sees running or unapproved results.
6. Coaching uses only approved Program B Run 2 or newer results.
   Program A and Run 1 stay locked.
7. Results never change the trading plan directly.
